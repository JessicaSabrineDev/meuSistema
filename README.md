meuSistema

Sistema simples desenvolvido para aprendizado de Node.js, Express e MySQL.

Tecnologias

- Node.js
- Express
- MySQL
- HTML
- JavaScript

Como rodar o projeto

1. Clonar o repositório:
   git clone https://github.com/jessicaSabrineDev/meuSistema.git

2. Entrar na pasta do projeto:
   cd meuSistema

3. Instalar as dependências:
   npm install

4. Rodar o servidor:
   node server.js

5. Abrir no navegador:
   http://localhost:3000

Não usar live server

Funcionalidades

- Cadastro de dados
- Listagem de dados
- Atualização de dados
- Exclusão de dados
- Conexão com banco de dados MySQL

Objetivo

Este projeto foi desenvolvido para aprendizado de desenvolvimento web utilizando Node.js, banco de dados MySQL e criação de APIs.
